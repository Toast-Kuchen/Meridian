# MERIDIAN v3 – alle Dateien in einer Ebene
Lokal: `python3 -m http.server 8080` im Ordner, dann http://localhost:8080
Veröffentlichen: alle Dateien auf einen HTTPS-Host. iPhone: Safari → Teilen → Zum Home-Bildschirm.
Offline-Test: einmal online laden, Flugmodus, App starten. Eigene Sounds: sound-*.wav ersetzen und V in service-worker.js hochzählen.
Hinweis: Spielstände von v2 sind nicht kompatibel (neues Spiel startet automatisch).
